# 🏋️‍♂️ Workout Progress Tracker

A lightweight, local-first web application designed to log gym workouts, track weight progression, and categorize exercises by muscle groups. 

This project bridges data extraction (parsing legacy text notes) with a full-stack architecture.

## ⚙️ Tech Stack
* **Database:** SQLite (Lightweight, local relational data)
* **Backend:** Python (Data parsing script & API logic)
* **Frontend:** Vanilla JavaScript, HTML5, CSS3 (Mobile-first design)

## 📋 Features
- [ ] **Legacy Data Importer:** Python script utilizing `Regex` to parse and import historical workout data from raw `.txt` notes into the database.
- [ ] **Muscle Group Filtering:** Categorize and filter exercises (e.g., Legs, Chest, Back) for structured routines.
- [ ] **Progress Tracking:** Log sets, reps, and weights per exercise.
- [ ] **Mobile-Ready Interface:** Responsive web design meant to be used on a smartphone during workout sessions via a local network.

## 🗺️ Development Roadmap
- **Phase 1:** SQL Schema design & Database initialization.
- **Phase 2:** Legacy text parser development (Python).
- **Phase 3:** REST API development (Python/Node.js).
- **Phase 4:** Frontend UI/UX implementation.
